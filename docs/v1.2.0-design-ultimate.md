## 3. 拆分原则

- **不复用 design HTML 的内联 Vue3 cdn 写法** —— 用产品 Vue3 + `<script setup lang="ts">` + composition API
- **不复用 design HTML 的 .glass / .glass-hover / i- 之类 carbon-like class** —— 改用产品 tokens.css 既有 .stat-card / .ph-ic + 已有 wenxi .wx-surface / .stat-card-wx
- **view 路由独立** —— `/ultimate` 不替代 `/`（Dashboard.vue），新独立路由 + AppLayout 加入口；不破坏 v1.1.0 既有 dashboard
- **主题切换走现有 appStore.themeStyle**（已支持 indigo/wenxi）—— design v2.0 演示用，验证切换流畅
- **数据来源 100% 复用现有端点** —— 0 新增 server 端点；0 入侵
