**期望对齐目标**（以 `design/bxverse-ultimate-cockpit.html` v2 为准，**不参考** `_archive/bxverse-v2-full-cockpit.html`）：
- `/` 路由 Dashboard.vue 是产品"全景概览看板"主体（已存在，未改动）
- 左侧导航 w-16 6 一级 + icon + shortLabel（v1.1.0 既有 v2 风格）
- 修短 shortLabel 1-2 字（避免 3-4 字挤压：项目台→项目 / 发版向导→向导 / 审计比→审计）

## 5. lessons

1. **design 资产拆分前先看 v1.1.0 现状**：v1.1.0 Dashboard.vue 已经是 design ultimate-cockpit 风格的最终效果图，不需要新加独立路由。**先盘点 v1.x 现状**再决定是「升级既有」还是「新增独立路由」。
2. **product 与 design 验证对齐 = 截图对比**：用 Edge headless 拍 `127.0.0.1:5173/` 路由截图与 design 原型对比，识别 v1.1.0 现状与 design 差异点。**别只看 `/` 一个路由就发版**。
3. **shortLabel fit 容器**：`w-16` 64px 容器 + `w-10` 40px 按钮内 9px 字体仅 fit 1-2 字。3-4 字 shortLabel（项目台/发版向导/审计比）容易挤压换行。
4. **GitHub SSH 偶发 198.18.1.249 connection closed** → HTTPS 绕开（已在 memory 沉淀）。
5. **vite dev 默认只 listen IPv6 `::1`** → `server.host: '127.0.0.1'` 显式 IPv4（已在 memory 沉淀）。
